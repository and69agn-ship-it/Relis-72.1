# 🛒 Список покупок (Shopping List App - v72)

Сучасний, зручний та мобільний веб-додаток для керування списками покупок та каталогом товарів.

## Можливості
- **Декілька списків покупок**: Створюйте окремі списки (Супермаркет, Дім, Святковий стіл тощо).
- **Каталог товарів з ієрархією**: Категорії, підкатегорії та товари з розумними іконками.
- **Швидкий пошук та фільтрація**: Миттєвий пошук товарів з можливістю швидкого додавання відсутніх товарів.
- **Улюблені товари (⭐)**: Зберігайте часті покупки для швидкого доступу.
- **Локальне схоплення (LocalStorage)**: Усі дані надійно зберігаються на вашому пристрої.
- **Адаптивний мобільний дизайн**: Оптимізовано для смартфонів та планшетів.

## Виправлення та оновлення в релізі v72:
- Виправлено навігацію після додавання товару з пошуку: кнопка «Додати з каталогу» у вікні підтвердження тепер очищує пошуковий запит і повертає користувача до повного перегляду каталогу категорій.

## Як запустити
Просто відкрийте `index.html` у будь-якому сучасному веб-браузері або розгорніть на GitHub Pages!
